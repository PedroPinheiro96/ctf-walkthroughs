A collection of detailed CTF walkthroughs covering enumeration, exploitation, privilege escalation, web vulnerabilities, hash cracking, reverse shells, Active Directory, and more.

This repository documents my learning journey in cybersecurity and penetration testing through hands-on CTF-style labs and vulnerable machines.

Each walkthrough includes:
- Reconnaissance and enumeration steps
- Exploitation methodology
- Privilege escalation techniques
- Commands and tooling used
- Lessons learned and mitigations
